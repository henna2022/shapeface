# 도형얼굴

얼굴 사진을 동그라미·세모·네모로 바꿔 유아가 도형을 배우는 웹앱. 태블릿 브라우저용.
계획서: Downloads/도형변환_교육프로그램_보고서_v3.docx

## 실행
정적 파일 두 개(index.html, app.js). 카메라는 https 또는 localhost에서만 열린다.

```bash
python3 -m http.server 8787
```

## 구조
- 얼굴 인식: MediaPipe Face Landmarker (CDN, 478점). 사진은 저장하지 않고 인식 직후 버림.
- 도형 20개: tier 1(얼굴·눈 2) → 2(코·입·눈썹 2) → 3(귀·볼·눈동자·콧구멍·이·턱·이마·머리).
- 활동: 이름 듣기 / 찾기 / 구별하기 / 속성 보기(꼭짓점 세기) / 만들기(드래그) / 보상(3·7·20개) / 인쇄(활동지 포함).
- 차시 1~5는 app.js의 LESSONS. 음성은 speechSynthesis ko-KR.
- 오른쪽 위 ⚙ 가 교사용 패널(차시·활동·도형 수·인쇄·새로 찍기).
