# 도형얼굴

카메라로 얼굴을 찾아 눈·코·입을 동그라미·세모·네모로 바꿔 그리고, 그 얼굴 위에서 도형 이름 듣기·찾기·구별하기·꼭짓점 세기·만들기를 하는 유아 도형 학습 웹앱. 태블릿 브라우저용.
영상 처리는 전부 브라우저 안에서 일어나고 **영상과 얼굴 좌표는 어디에도 전송되지 않습니다.**
계획서: Downloads/도형변환_교육프로그램_보고서_v3.docx

## 파일
- `index.html` : 앱 전체 (MediaPipe Face Landmarker CDN, 음성은 브라우저 speechSynthesis)

## 흐름
1. 시작하기 → 카메라 허용 → 실시간으로 얼굴이 도형으로 보임 (도형 더 많이: 3 → 7 → 20개)
2. 찰칵 : 3초 카운트다운 후 촬영, 사진은 좌표만 남기고 버림
3. 놀이 화면 : 1~5차시 활동. 아이 버튼은 다시·다음 둘뿐, 안내는 음성
4. 보상 화면에서 다음을 누르면 3 → 7 → 20개 → 완성 카드 (사진 저장 / 다시 하기)

오른쪽 위 ⚙ 가 교사용 패널: 차시·활동 바로 가기, 도형 수, 소리, 인쇄(결과 그림 + 보호자용 활동지), 새로 찍기.
차시 구성은 `index.html`의 `LESSONS`, 활동 종류는 `MODES`.

## 컴퓨터에서 테스트 (카메라 없이)
주소 뒤에 `?img=사진경로` 를 붙이면 카메라 대신 그 사진으로 동작합니다. 시작 화면의 "사진 파일로 하기"는 사진 한 장으로 바로 놀이 화면으로 갑니다.

    python3 -m http.server 8787

## 배포
카메라는 https 주소에서만 열립니다. ai-persona와 같은 방식으로 GitHub Pages(public 저장소, Settings → Pages → main / root)에 올리면 됩니다.
